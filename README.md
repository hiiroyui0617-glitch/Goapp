# その一手、いかんです。 — 囲碁アプリ

「囲碁に、説明責任を。」をテーマにした無料のスマホ対応 Web / PWA 囲碁ゲーム。
特定の政治家・政党・行政機関とは関係のない架空の政治会見風パロディです。

## アクセス / 公開

GitHub Pages を利用できます。リポジトリの Settings → Pages で
Deploy from a branch → main / (root) を設定してください。

想定URL: https://hiiroyui0617-glitch.github.io/Goapp/

iPhoneではSafariの共有から「ホーム画面に追加」を選びます。
ソースをPC上で開く場合は、ES modulesのためHTTPサーバーから配信してください。

    python -m http.server 8000

その後 http://localhost:8000 にアクセスします。外部API・課金は不要です。

## 実装機能

- 人間 vs CPU、人間 vs 人間（同じ端末）
- 9路盤・13路盤・19路盤、コミ 0 / 0.5 / 5.5 / 6.5 / 7.5、先後選択
- 盤上の指に追従する半透明の着手予測石。離したときに着手
- 囲碁の石取り・自殺手禁止・位置的スーパーコウ、連続パス終局
- ヒント（先読みを含むCPUの参考候補）
- 初心者向け勢力分布の近似表示（確定地とは異なる）
- 地合：黒地には黒点、白地には白点を表示。数字は黒/白を別色のカードで示し、地・アゲハマ・コミを内訳表示
- 死に石のグループをタップで指定、手動判定の日本式地合計算
- CPUの無意味な再侵入・自陣の眼埋め・自滅手の抑制、アタリの攻防・先読みを含むCPUの改善
- CPUの思考処理をWeb Workerで別スレッド化（非対応ブラウザではメインスレッド処理）
- 棋力の難易度ラベル：15級〜1級・初段・二段（厳密な実力保証はありません）
- 対局の自動保存・再開、オフラインPWA
- 音量、反転、バイブレーション、最終手表示、着手速度、カットイン、音声読み上げ

## 2026年11月22日 改修（スマホ CPU・SE・イラスト）

- iPhone Safariで Web Worker が応答せずCPUが止まるケース向けに、**3.5秒の監視タイマー**を追加。未応答ならメインスレッドで負荷の小さい評価処理を行って着手します。
- AI Workerへ送る盤面を軽量化し、待った・ホーム復帰で古い計算結果が混じらないようにしました。
- スマホのホーム画面から起動したPWAの更新反映を改善し、新しいService Workerへ切り替わる際に再読み込みします。
- 既存の電子音っぽい着手音と短い外部クリック音を廃止。**打石の瞬間的な衝撃・木製碁盤の共鳴・高周波の減衰を組み合わせた独自のWeb Audio音**に変更。複数バリエーション、石取り時の追加音に対応し、オフラインでも鳴ります。
- CC0の囲碁石実録音素材も調査しましたが、音声配信先へアクセスできず取得できなかったため**録音そのものはまだ使用していません**。現在の音は録音ではなく物理特性を参考にした合成です。
- 銀髪・緑のスーツ・赤いネクタイのオリジナル政治家風キャラクターのSVGカットイン画像5種類を`assets/cutins/`に追加。
  - 黒地や白地と無関係なUI演出として、**人間が石を取る → 支持率上昇**、**CPUに取られる → 支持率下落**、**勝ち → 当選**、**負け・投了 → 遺憾です**、**待った → 記憶にございません**。
  - 下側から約0.36秒でスライドインし、Web Speech APIの音声読み上げが終わるまで表示。音声が使えない場合は約1.6秒、ブラウザが読み上げ完了を通知しない場合はタイムアウトで閉じます。
  - 以前生成した高精細PNG原画5枚は、GitHubに組み込んだSVG版とは別の制作素材です。

音声はOSの日本語読み上げであり、特定の政治家・ゲームキャラクターの音声を模倣したものではありません。
OS/ブラウザの読み上げ可否は端末設定に依存します。iOSでは音声や振動が使えない場合があります。

## CPUについての現状の限界

CPUは「近傍の形、呼吸点、アタリ、つながり、眼、死に石、囲いの地、相手の有力応手」から
スコアを計算する独自の軽量CPUです。上位プリセットでは相手の応手をいくつか先読みします。

**初段・二段というラベルは、実際の人間の初段・二段に匹敵する強さを保証するものではありません。**
その水準を目指すには、KataGoやGNU Goなどの実戦エンジンを適切に組み込んで棋力を検証する必要があります。
現在の実装は「以前より自滅しにくいCPUへの改善」であり、正式な棋力認定ではありません。

CPUが逃げ切れない局面や死活・コウなどの複雑な問題を正しく判断できないことがあります。
囲みきっていない大きな空き領域は確保した地とみなさない安全措置があります。

## 地合計算の注意点

日本式の「地＋アゲハマ＋コミ」で算出し、死に石の指定は手動です。
自動死活判定、セキ、持続的なコウ争いなど日本囲碁規約の特殊な裁定まで
完全に実装しているわけではありません。対局終了時は双方合意の上で結果を確定してください。
