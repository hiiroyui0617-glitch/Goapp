# その一手、いかんです。

政治会見のような言い回しで囲碁を楽しむ、スマホ対応の無料・広告なしWebアプリ。すべての囲碁処理はブラウザ内で動作します。特定の政治家・政党・行政機関とは無関係の創作パロディです。

## 機能

- 木目調の碁盤と、指に追従する半透明の着手プレビュー（指を離すと確定）
- 9路盤・13路盤・19路盤、コミ0 / 0.5 / 5.5 / 6.5 / 7.5
- 人間 vs CPU、人間 vs 人間（同一端末）、先手・後手選択
- CPU難易度15級～1級・初段・二段（**簡易AIの難易度ラベルであり、その棋力を保証するものではありません**）
- 石の取り、呼吸点、自殺手禁止、同一盤面の再現を禁止するコウ（位置的スーパーコウ）
- パス、待った、ヒント（**簡易AIの参考候補手。厳密な最善手・定石ではありません**）
- 初心者向け「ここに打つと勢力圏がどう変わる？」プレビュー（**勢力圏の近似。地として確保したマス数ではありません**）
- 日本式の地＋アゲハマ＋コミによる地合計算と死に石グループの手動指定（双方が死に石に合意する前提）
- 音量、盤面の180度反転、バイブレーション、最終手のマーク、CPU着手速度
- 端末内での自動保存・再開、PWAオフライン対応

## 動かし方

**GitHub Pages**: リポジトリの Settings → Pages で Deploy from a branch → main / (root) を有効化します。公開URLは GitHub Pages の画面で確認してください。iPhoneではSafariで開き、共有 → ホーム画面に追加 からアプリ風に起動できます。

**PCローカル**: ESモジュールを使うため index.html を直接 file:// で開かず、HTTPで配信してください。

例: python -m http.server 8000

その後 http://localhost:8000 にアクセスします。

## 制約・留意事項

- このCPUは独自の軽量評価関数を使います。KataGoやGNU Goなどの実戦エンジンは組み込んでいません。二段ラベルでも二段相当の実力があるとは限りません。
- ヒントは候補手の提示であり、プロの定石データベースを参照していません。
- 初心者モードは周囲の石から勢力の増分を可視化するための独自指標であり、死活やヨセを判定するものではありません。
- 地合計算は死に石を自動判定しません。盤上で該当グループをタップし、取り除く前提の計算です。セキや複雑な日本ルールの裁定、手入れの特殊ケースには対応していません。
- 位置的スーパーコウを採用しているため、日本囲碁規約の複雑なコウ裁定とは完全には一致しません。
- 振動APIはiOS Safariなどでは動作しない場合があります。
- 保存にはブラウザの localStorage を使います。閲覧データ削除で消えることがあります。
- サービスワーカーの更新直後は、ページを再読み込みしてください。

## 技術構成

HTML + CSS + Canvas 2D + Vanilla JavaScript (ES Modules)。外部サーバー・有料API・広告SDKは不要です。

## UIのメッセージ例

- 待った：「記憶にございません。」
- パス：「答弁を差し控えます。」
- 投了：「遺憾です。」
- 大差での投了：「誠に遺憾です。」
- ヒント：「専門家の参考意見を提出しました。」
- 対局開始：「新たな審議が始まりました。」

特定個人の肖像・声・実在する公的機関の紋章を使用せず、架空の「囲碁対局庁」という世界観にしています。
