## カットインと搭載音声（2026-11-22更新）

ユーザー提供の「voice.zip」のMP3 **11本を元データそのままで公開リポジトリの** \`assets/voices/\` **に搭載しました。** \`skip.mp3\` だけは対局イベントに合わせて \`pass.mp3\` に名称を変更しています（中身は元のMP3と完全一致）。

11種類の演出にはオリジナル政治家風キャラクターSVG画像を割り当てています。画像は画面下からスライドインし、実際のMP3の再生終了イベントに合わせて退出します。約3.2秒以内に音声が読めない場合は端末の読み上げへ切り替え、再生が異常に長い場合は安全タイマーで閉じます。

iPhoneのブラウザでは非同期の音声再生が制限される場合があるため、ユーザーの操作でWeb Audioを有効化し、MP3をデコードして鳴らす方式を採用しています。ユーザーが設定で音声を無効化すると、カットイン自体は短時間表示します。

**音声の公開について:** 今回の11本はGitHub Pagesで誰でもアクセスして再生・ダウンロードできます。提供された音源の第三者の音声モデル・サービスに関する配布条件や権利については、アプリのコード側では検証できません。公開利用前にご自身で確認してください。アプリは実在する政治家本人の公式音声を自称しません。

### 自分の音声への差し替え（任意）

「設定 → カットイン音声」から、MP3の個別登録や11本入りZIPの一括登録ができます。個人の差し替え音源はこの端末のIndexedDB内だけに保存され、外部へアップロードされません。個別登録を消すとアプリ標準のMP3に戻ります。

元のZIPに含まれる \`voice/skip.mp3\` は \`pass.mp3\` として認識されます。ZIPは20MB以下、各MP3は8MB以下で、全11本が揃っている必要があります。ZIP検証に失敗した場合、保存中の差し替え音声を変更しません。ZIP解析にはMITライセンスのJSZipを同梱しています（\`vendor/JSZIP_LICENSE.md\`）。

## CPUとKataGo

**通常対局のCPU:** 独自の軽量評価・限定的な応手の先読みを行います。「15級〜二段」は難易度選択の名前であり、その段級位の棋力を保証しません。厳しいコウ・死活・セキ・ヨセ等で誤る可能性があります。

**KataGoモード:** MITライセンスの [Web KaTrain](https://github.com/Sir-Teo/web-katrain) を \`katago/\` にビルドして利用しています。これは通常対局とは別画面です。ニューラルネットワーク・MCTS・モデルの処理にはメモリと時間を要し、とくにiPhoneでは高負荷になることがあります。付属モデルは小型のテスト用で、段位の実力を保証しません。元プロジェクトのライセンスは \`katago/UPSTREAM_LICENSE\` に保存しています。

**採点:** 日本式の「地＋アゲハマ＋コミ」を近似的に計算します。死に石の手動指定・双方合意が必要で、公式の日本囲碁規約の特殊な終局判定を完全には網羅していません。

## 実行・更新・テスト

GitHub Pagesを使う場合、\`Settings → Pages → Deploy from a branch → main / (root)\` に設定してください。iPhoneはSafariの「共有 → ホーム画面に追加」からアプリ化できます。更新時には一度閉じてSafariで再読み込みしてください。

PCのローカル起動（Node等でも可）:

\`\`\`sh
python -m http.server 8000
# ブラウザで http://localhost:8000/
\`\`\`

単なる \`file://\` での起動はES Modulesの読み込み制限を受けます。テストにはNode 22以降を使用します。

\`\`\`sh
npm test
\`\`\`

元の囲碁エンジン、音声ZIP形式、カットインの再生完了、GitHub公開ファイルの存在等を回帰テストしています。ただしiPhone 13での実機音声再生・ブラウザ版KataGoの棋力の最終確認は必要です。
